A note on Logistic Regression

1. Binary Outcomes and Probabilities

Logistic regression is used when the output \(Y\) is binary, i.e., \(Y \in \{0, 1\}\). The goal is to model the conditional probability \(P(Y = 1 | \mathbf{X})\), where \(\mathbf{X}\) is a vector of input features.

We define: \[ p(\mathbf{X}) = P(Y = 1 | \mathbf{X}) \]

So \(p(\mathbf{X})\) is the conditional probability of \(Y = 1\) given \(\mathbf{X}\). Since probabilities are bounded between 0 and 1, direct modeling using a linear function \(\mathbf{X} \cdot \boldsymbol{\beta}\) is unsuitable because it is unbounded.

2. The Logistic Function

To ensure \(p(\mathbf{X})\) lies within the range \([0, 1]\), the logistic function is used: \[ p(\mathbf{X}) = \frac{1}{1 + e^{-(\beta_0 + \mathbf{X} \cdot \boldsymbol{\beta})}} \]

Note Sigmoid Function: is generally defined as \(\frac{1}{1 + e^{-x}}\). Hence the logistic function is a special case of the sigmoid function, where the linear combination \(\beta_0 + \mathbf{X} \cdot \boldsymbol{\beta}\) is used as the input. Hence \[ p(\mathbf{X}) = \frac{1}{1 + e^{-(\beta_0 + \mathbf{X} \cdot \boldsymbol{\beta})}} = \sigma(\beta_0 + \mathbf{X} \cdot \boldsymbol{\beta}) \]

This formulation introduces two components: - \(\beta_0\): The intercept term. - \(\boldsymbol{\beta}\): The coefficient vector corresponding to the features in \(\mathbf{X}\).

The logistic function transforms the linear combination \(z = \beta_0 + \mathbf{X} \cdot \boldsymbol{\beta}\) into a probability.

3. Odds and Log-Odds (Logit) Transformation

Instead of modeling probabilities directly, logistic regression models the log-odds: \[ \text{logit}(p(\mathbf{X})) = \log \left( \frac{p(\mathbf{X})}{1 - p(\mathbf{X})} \right) = \beta_0 + \mathbf{X} \cdot \boldsymbol{\beta} \]

Here: - \(p(\mathbf{X})\) from \([0, 1]\) is the conditional probability of \(Y = 1\) given \(\mathbf{X}\). - The logit function maps \(p(\mathbf{X})\) from \([0, 1]\) to \((-\infty, \infty)\), enabling linear modeling.

4. Likelihood Function

Logistic regression uses Maximum Likelihood Estimation (MLE) to estimate \(\beta_0\) and \(\boldsymbol{\beta}\). The likelihood for \(n\) independent observations \(\{(y_i, \mathbf{x}_i)\}\) is: \[ L(\beta_0, \boldsymbol{\beta}) = \prod_{i=1}^n p(\mathbf{x}_i)^{y_i} (1 - p(\mathbf{x}_i))^{1 - y_i} \]

Taking the natural logarithm (log-likelihood): \[ \ell(\beta_0, \boldsymbol{\beta}) = \sum_{i=1}^n \left[ y_i \log(p(\mathbf{x}_i)) + (1 - y_i) \log(1 - p(\mathbf{x}_i)) \right] \]

5. Gradient of the Log-Likelihood

The gradient of the log-likelihood with respect to \(\boldsymbol{\beta}\) is: \[ \frac{\partial \ell}{\partial \beta_j} = \sum_{i=1}^n \left( y_i - p(\mathbf{x}_i) \right) x_{ij} \]

Here: - \(p(\mathbf{x}_i) = \frac{1}{1 + e^{-(\beta_0 + \mathbf{x}_i \cdot \boldsymbol{\beta})}}\)

This gradient is used in iterative optimization algorithms, like gradient ascent, to find the parameters \(\beta_0, \boldsymbol{\beta}\) that maximize the log-likelihood.

7. Key Characteristics

  • Logistic regression not only provides class predictions but also estimates probabilities.
  • It models the log-odds linearly, ensuring interpretability and bounded probabilities.

This mathematical framework underpins logistic regression as a tool for binary classification and probability estimation.

Logistic Regression MLE

In logistic regression, the response variable \(Y\) is binary \(Y \in \{0, 1\}\). For a given set of features \(\mathbf{x}_i\), the probability of \(Y_i = 1\) is modeled using the logistic (sigmoid) function:

\[ p(\mathbf{x}_i) = \Pr(Y_i = 1 | \mathbf{x}_i) = \frac{1}{1 + e^{-(\beta_0 + \mathbf{x}_i^\top \boldsymbol{\beta})}}. \]

For \(Y_i = 0\), the probability is:

\[ \Pr(Y_i = 0 | \mathbf{x}_i) = 1 - p(\mathbf{x}_i). \]

Thus, the conditional probability (or likelihood) for a single observation \((Y_i, \mathbf{x}_i)\) can be expressed compactly as:

\[ \Pr(Y_i | \mathbf{x}_i) = p(\mathbf{x}_i)^{Y_i} \cdot (1 - p(\mathbf{x}_i))^{1 - Y_i}. \]

This formulation captures both cases (\(Y_i = 1\) and \(Y_i = 0\)).

Joint Probability of Observations

Assuming the observations are independent, the joint probability (likelihood function) for the entire dataset \(\{(Y_i, \mathbf{x}_i)\}_{i=1}^n\) is the product of the individual probabilities:

\[ L(\beta_0, \boldsymbol{\beta}) = \prod_{i=1}^n \Pr(Y_i | \mathbf{x}_i). \]

Substituting the individual likelihood expression:

\[ L(\beta_0, \boldsymbol{\beta}) = \prod_{i=1}^n p(\mathbf{x}_i)^{Y_i} (1 - p(\mathbf{x}_i))^{1 - Y_i}. \]

Log-Likelihood Function

To simplify optimization, the log of the likelihood function, known as the log-likelihood, is used:

\[ \ell(\beta_0, \boldsymbol{\beta}) = \log L(\beta_0, \boldsymbol{\beta}) = \sum_{i=1}^n \left[ Y_i \log(p(\mathbf{x}_i)) + (1 - Y_i) \log(1 - p(\mathbf{x}_i)) \right]. \]

Substituting \(p(\mathbf{x}_i)\) into this expression:

\[ \ell(\beta_0, \boldsymbol{\beta}) = \sum_{i=1}^n \left[ Y_i (\beta_0 + \mathbf{x}_i^\top \boldsymbol{\beta}) - \log(1 + e^{\beta_0 + \mathbf{x}_i^\top \boldsymbol{\beta}}) \right]. \]

This form is more manageable for numerical optimization.
